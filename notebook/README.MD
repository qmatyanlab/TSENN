### Key Notebooks

- **`imaginary_part_prediction.ipynb`** — The **most essential notebook**, containing the main results reported in the paper.  
  It includes the reproducible model, saved checkpoints, and generated figures.

- **`multiple_material_prediction.ipynb`** — Demonstrates how to prepare lists of material structures and feed them into the model to directly obtain the predicted dielectric tensors.

- **`perturb_structure_prediction_shear.ipynb`** and **`perturb_structure_prediction_uniaxial.ipynb`** —  
  Showcase model predictions on **perturbed structures**, under *shear strain* and *uniaxial strain*, respectively.
